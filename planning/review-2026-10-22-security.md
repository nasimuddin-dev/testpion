# Security review — 2026-10-22 (commit 4d4b21a8)

Scope: Electron main (`apps/desktop/electron`), backend RPC (`apps/desktop/backend`), engine (`packages/core`), shared, CLI, MCP server, CI. Read-only review of the source; every finding cites the lines it was verified on. "unverified" marks a claim that needs a runtime check. Severity: **P0** exploitable from untrusted input · **P1** weakness · **P2** hardening.

Threat model used: (a) a workspace is untrusted content — it arrives by git clone, import (Postman/Bruno/HAR/zip/bundle), a shared session or a teammate; (b) the renderer is trusted today but the cloud version makes the RPC surface reachable by other users; (c) agents (MCP) act on the user's behalf and read API responses; (d) the machine's network is private by default (desktop) and must become public-only on a server (`blockPrivateNetworks`).

## 1. Script sandbox (QuickJS)

## 2. RPC surface (`Backend.invoke`, handlers)

Verified: only own handler names are callable (`backend.ts:541-542`, `tests/unit/security-hardening.test.ts:20`); `checkRpcParams` runs before every handler (`backend.ts:554`); every handler has a parameter entry or is on a shrinking legacy list (`tests/unit/rpc-params-coverage.test.ts:31-42`); `safePath` resolves symlinks on both sides (`storage/fsutil.ts:94-98`, `workspace.ts:149-152`, `tests/unit/path-containment.test.ts`); test paths from AI/agents are checked lexically and really (`storage/test-path.ts`); the zip reader refuses `..`, absolute, backslash, links, bombs (`transfer/zip.ts:5-6`, `:143-145`); `output.save` never takes a path from the window (`handlers/output.ts:154`, `:170-172` sanitises the name; the OS dialog chooses the folder); `output.reveal` opens only files saved in this session and never launcher formats (`:51`, `:100`, `:266-282`); `app.openPath` only workspace folders (`handlers/app.ts:87-93`); `http.saveBody` only inside payloads/ (test `:30`); `audit-rpc-fuzz.test.ts` fuzzes every handler with bad input.
