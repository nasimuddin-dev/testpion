# Security review — 2026-10-27 (commit 208dd40c)

Scope: everything changed since the previous review (`4d4b21a8..HEAD`, 117 commits), with every fix of `planning/review-2026-10-22-security.md` re-checked in the code. Read-only; nothing was changed, no builds, no e2e. The only command run against the network was `npm audit --omit=dev --json`. Severity: **P0** exploitable / data loss · **P1** weakness · **P2** hardening. Every row names the lines it was verified on.

Threat model as before: a workspace is untrusted content (git, import, teammate); the renderer is trusted today but the RPC surface becomes multi-user in the cloud; agents (MCP) act on the person's behalf and read API responses, which can carry prompt injection; the LAN is hostile once the Debugger listens on it; a shared server must be public-only (`blockPrivateNetworks`) and must not read the host's files or environment.
