### P1 (grouped)

**Security**
- MCP server resolves `{{$env.NAME}}` for every environment variable by default (`engine.ts:104` falls back to `'all'`; `send_request` takes any URL/headers without confirmation): a prompt-injected agent exfiltrates host keys. Default to `[]` outside the CLI run commands.
- undici 8.11.2 carries 8 new advisories (4 high, incl. a TLS-options-dropped validation bypass in the `Agent({connect})` shape `net/proxy.ts:149-152` uses); zod, body-parser, hono, qs, ip-address, fast-uri too. `npm audit --omit=dev`: 4 high + 4 moderate; the CI audit gate is red.
- LAN pairing secret forwarded to WebSocket servers on upgrades (`proxy.ts:921-925`; `forward()` strips it at `:733`).
- (P2 but security-relevant) `set_settings`/`settings.import` can retarget the proxy, widen `{{$env}}`, shrink redaction behind a confirmation that names keys only; "Capture all traffic" autosaves decrypted machine-wide traffic (tokens in bodies) into the open workspace every minute; `RequestContext.can()` never consulted and no host sets `CallMeta.user`; `debug.openBrowser`/`selfTest`/`start` lack parameter entries and `startUrl` is Chrome's last argv (a `--` URL is a switch); worker require bridge has no request number (a late answer becomes the next package's source).

**Robustness**
- System proxy restore cut, partial or stale: 2 s quit cap vs two PowerShell spawns; partial macOS/GNOME set with the snapshot dropped; port change leaves the OS at the old port (`backend.ts:924`, `capture.ts:255-271`, `debugger.ts:514-515`).
- Certificate install deletes the trusted root before adding (a refused UAC leaves none); trust check returns `false` on any error and `undefined` on Linux → the dialog and the install run on every click (`certificate.ts:189-228`, `DebuggerView.tsx:328-343`); macOS/Linux never remove the stale same-name root, so the by-hash check stays "not trusted" after a good install.
- Five async writers not serialised: on a Windows EBUSY retry older test-file / providers / MCP servers / baseline / package bytes overwrite newer ones silently (`workspace.ts:414-829`).
- Housekeeping deletes another process's run (a CLI run older than an hour without a summary) 5 s after open, and the sweep is synchronous on the main thread (`housekeeping.ts:100-131`, `backend-health.ts:134-142`).
- Script cancellation and the require bridge: an abort before `acquire` never fires (the script runs to its timeout and "succeeds"); a 5 s busy main thread makes `tp.require` return `undefined` (`script-runner-workers.ts:164-232`, `script-worker.ts:29-35`).
- Windows child processes outlive their timeouts: `shell: true` + timeout kills `cmd.exe` only (a hung `az` blocks every RPC needing that secret, `external-secrets.ts:96-98`); npx-started MCP servers leave a node grandchild per reconnect (`mcp/client.ts:277-291`).
- Not fixed from 10-22: C-4 workspace lock, C-5 double send, O-3 sync log appends; partial: C-6, R-7, D-4, O-2, audit-edge sequencing.
- `captureAll` runs `systemProxy(true)` inside `attempt()` (error swallowed) and then still installs the certificate; chips (`quick`, with `Date.now()` ids) and `hideTunnels` are saved into filter presets; the e2e `rag-evaluation` difference (0.778 vs 1) is completion order in the plan (`res.items[0]` with concurrency 4), not the metric.

## Suggested fix order

1. **Machine safety first**: the system proxy (persist the snapshot before the change, repair at startup, never snapshot our own address, restore before the quit cap, re-point on port change) and the certificate install order (add, then delete others by hash; tri-state trust with a cached answer; macOS/Linux stale root).
2. **Dependencies and the two security P1s**: undici/zod/body-parser/hono/qs/ip-address/fast-uri floors (CI audit gate green), `{{$env}}` default `[]` on the MCP server, drop `proxy-authorization` on upgrades.
3. **Debugger correctness**: one shared rule matcher for chips and engine (OR for capture-only), rule names from the match, chips out of presets, `captureAll` stops on a failed proxy switch.
4. **Main-thread blocks**: GraphQL/gRPC/subscription through `summarizeResponse`, async sliced HAR writes (await the autosave in `release`), secrets scan capped at 256 KB, TimelinePanel memo/cap, cached globs, the two uncached readers, debugger per-sync passes; then turn the worker pool on for the desktop (fix the queued-job hang and the abort-before-acquire first; `script-worker.cjs` into `asarUnpack`).
5. **Robustness P1s**: serialise the five async writers, housekeeping pid file + async sweep, `taskkill /T` for shell children, MCP grandchildren, the three 10-22 leftovers (C-4, C-5, O-3), the `rag-evaluation` plan fix.
6. **UX**: one start control, one place per Clear/Save, the three decrypt paths through `readHttps`, CA variables in the opened terminal, contrast + aria on the chip, docs/CHANGELOG/llms.txt/screenshots, e2e for today's features, CLI/MCP surfaces for capture-all/decrypt/certificate/inspector data.
7. **Cloud stage 2** in the order the scalability file proposes (close stage-1 gaps 3 d → async stores 3 w → mandatory revisions + `col.patch` 1.5 w → per-store caches 1 w → run-service 1 w → workspace identity by id 4 d → contract completion 1 w → ratchets/dedupe/splits 3 d → cloud host 2 w).
