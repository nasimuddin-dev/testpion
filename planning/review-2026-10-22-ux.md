Read-only review of TestPion at `main` `4d4b21a8` (2026-10-22). Nothing was edited, committed or run except the CLI
(`packages/cli/bin/testpion.js`) read-only against `examples/veterinary-workspace`, `git log`, and greps. Paths are
relative to `apps/desktop/src` unless they start with `packages/`, `docs/`, `apps/desktop/electron`, `backend/` or

Yesterday's two audits (`planning/ui-audit-2026-10-21-ux.md`, `-consistency.md`) are fixed and are not repeated here:

not: first run, the map of the app, the core flows end to end, copy, accessibility beyond names, docs coverage, the CLI
and MCP as an agent sees them, and Settings.

Severity: **P0** stuck or data loss · **P1** confusing or a costly detour · **P2** polish.

## 2. Information architecture

The rail (`components/nav.tsx:10-36`, `lib/rail.ts:16,28-31`) shows Home · Collections (the explorer and every request
editor) · Tests (test files, flows, suites, runs) · Environments · History, with Debugger · Monitors · Load · AI Lab ·
Evaluations · Traces · Git under **More…** and Settings pinned at the bottom; it is customisable by right-click, per
computer, with Ctrl+Alt+1…9 following the shown order (`Rail.tsx:86-88`). Not too long (5 shown, 7 hidden).

Search (`packages/core/src/storage/search.ts:12,111-178,203-208`) indexes collections, requests (name, method, URL
only), GraphQL, environments, variables (unless secret), MCP servers, providers, API definitions (path only), datasets
(name only), test files (first 200 KB), library kinds with `search: true`, plus history (20), traces (10), runs (10).
**Not indexed:** folders, saved examples, request headers/bodies/scripts, OpenAPI operations, Debugger exchanges and
sessions, cookies, certificates, git commits, Settings tabs, docs pages. Quick Open (`lib/quick-open.ts`) is the same
hits + recent items + `>` commands + `@` focused-editor commands (only script editors and the flow canvas register,
`lib/palette-context.ts`) + `#` environments/variables + `~` Ask + `?` help.

Only reachable from the status bar, a ⋯ menu or the palette (`components/StatusBarTools.tsx:27-32`, `Shell.tsx:212-258`,
`App.tsx:395-476`): Cookies… (Tools menu only), Find & replace in a collection… (Tools only), Share a debugger
session… (palette `App.tsx:439` only), Find variable usages / rename everywhere (palette `:453` only; Environments
view **UNVERIFIED**), Logs (status bar + palette), Feedback (status bar, palette, Settings).
