## 6. Top 10, ranked

1. **The system proxy outlives TestPion** (P0, `capture.ts:240-273`, `handlers/debugger-state.ts:49`, no startup repair): a kill, a crash, or the quit caps leave every program on the machine without a network, and the next capture snapshots the broken state so Stop restores it. Persist the snapshot to disk before the change, repair at startup, never snapshot our own address.
2. **The script worker pool hangs queued jobs** (P0, `script-runner-workers.ts:150-152`): an unhealthy release never serves `waiting` nor spawns a replacement; a cancelled or watchdog-killed script with others queued stalls the run forever. Spawn and serve in `release`.
3. **Debugger session writes at Stop / Save / quit** (P1, `handlers/debugger.ts:317-323, 333-337, 382-394`): a plain synchronous `writeFileSync` (the comment says atomic) of a pretty-printed HAR that blocks the main thread for seconds, and an autosave in flight that `release` neither awaits nor sees as dirty — a kill truncates the file and loses the previous autosave, a quit drops up to 60 s of traffic and leaves `autosave.har.tmp`. Atomic + sliced write, await the in-flight autosave.
4. **System proxy restore cut, partial, or stale** (P1, `backend.ts:924` 2 s cap vs two PowerShell spawns after a sync write; `capture.ts:255-271` partial macOS / GNOME set with the snapshot dropped; `debugger.ts:514-515` port change leaves the OS at the old port). Restore first with its own cap, undo on partial failure, re-point on port change.
5. **Certificate install deletes the trusted root; the trust check prompts on every error** (P1, `certificate.ts:189-190, 218-228`, `DebuggerView.tsx:328-343`): delete-by-name then an add the user can refuse; `false` on any error and `undefined` on Linux both open the dialog and the install path. Add first, delete others by hash; tri-state with a cached answer.
6. **Five async writers are not serialised** (P1, `workspace.ts:414-416, 597-599, 636-639, 708-710, 827-829`): on a Windows EBUSY retry the older test file / providers / MCP servers / baseline / package bytes overwrite the newer ones, silently. Wrap in `serial()`.
7. **Housekeeping deletes another process's run and freezes the window** (P1, `housekeeping.ts:100-131`, `backend-health.ts:134-142`): a CLI run older than an hour without a summary is swept 5 s after open; the sweep is synchronous on the main thread. A `.running` pid file; async batches or a worker.
8. **Quick filters disagree with the rules they stand for** (P1 + P2, `quick-filter.ts:19-28` vs `rules.ts:219-235, 411-416`, `DebuggerGrid.tsx:272`): two Capture-only chips AND in the window, OR in the engine → an empty grid while the engine captures; glob / case / port / list semantics drift; rule names saying `!=` for a rule that matches `=`. Share the matcher; fix the name.
9. **Script cancellation and the require bridge return wrong results** (P1, `script-runner-workers.ts:164-165, 216-232`, `script-worker.ts:29-35`): an abort before `acquire` never fires (the script runs to its timeout and "succeeds"); a 5 s busy main thread makes `tp.require` return `undefined`; a late answer can be delivered to the next require. Check after acquire; a sequence tag in the shared buffer.
