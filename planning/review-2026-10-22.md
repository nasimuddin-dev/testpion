### P1 (grouped)

**Security**
- `.local/trust.json` lives inside the workspace: a cloned repo arrives pre-trusted (MCP stdio commands, secret-manager CLIs run without the prompt). Move trust to the app dir keyed by real path; imports must refuse to write `.local/`. (`storage/trust.ts:18`, `handlers/mcp.ts:87-96`, `vars/external-secrets.ts:225`)
- Debugger LAN mode is an unauthenticated open proxy on 0.0.0.0 that forwards any URL/CONNECT including loopback. Pairing secret + refuse loopback/link-local targets. (`debugger/proxy.ts:1008`)
- Scripts read every secret (`tp.vault.get`, `tp.environment.get`) and `tp.sendRequest` to any host with no per-workspace trust. (`scripts/prelude.ts:668-674`, `scripts/bridge.ts:75-81`)
- `@modelcontextprotocol/sdk` 1.30.1 re-sends custom headers across cross-origin redirects; upgrade ≥1.32 and `redirect: 'manual'`. (`protocols/mcp/client.ts:285-287`)
- Linux `basic_text` safeStorage backend never checked: secrets may be stored under a hard-coded key (unverified at runtime). (`electron/main.ts:374-379`, `secrets.ts:101,112`)
- MCP confirmations are advisory without elicitation; `ai_run_task` and send/run have no confirm; AI spend caps default to none. (`mcp-server/tool-contract.ts:421-441,527`)
- A dozen RPCs accept absolute host paths (`git.clone dest`, `ws.open`, `col.previewDataFile`, `protoFiles`, client cert paths, `terminal cwd`): arbitrary read / cross-tenant on a server. One `hostPath()` gate behind a host capability, enumerated in `rpc-params.ts`.

**Robustness**
- Workspace switch during a run closes the SQLite store the run writes to: run ends in error, never reaches history. (`backend.ts:413` vs `:758,779,789`)
- `collectionView` cache entries are never deleted: every save keeps another parsed, frozen copy for the process lifetime. (`storage/workspace.ts:224-242`)
- Renderer crash only `console.error`s: white dead window, nothing in app.log. (`electron/main.ts:230`)
- History/trace bookkeeping after a successful send is inside the try, and the catch calls `addHistory` again: disk full / read-only turns a successful send into an error and loses the response. (`backend/send.ts:141-159,215-218`, `errors.ts:138-143`)
- Damaged/locked `database.sqlite` silently falls back to `metadata.jsonl`: history looks empty and diverges. (`storage/metastore.ts:905-915`)
- AI provider fetches and SSE streams have no timeout / idle timeout outside tests. (`ai/http.ts:31-36,109-127`)
- CLI has no `unhandledRejection` handler: exits 1 = `EXIT.TEST_FAILURE`. (`packages/cli/bin/testpion.js:63-73`)
- `before-quit` does `void backend.dispose()`: cookie flush, Kafka close, JSONL compaction, dirty Debugger session cut off. (`electron/main.ts:485-487`)
- `slugify` keeps Windows device names: a collection named "CON" writes `collections/con.json` (unverified at runtime). (`util/ids.ts:47-55`)

**Scalability**
- Runs have no retention and every run writes 4 reports; whole-document rewrites (`saveCollection`, `saveLibrary` one file per kind, `col.save`/`col.list` whole collections over IPC); `collectionFile` falls back to reading every collection's text.
- `Atomics.wait` sleeps the whole process up to 1.45 s on a refused rename. (`storage/fsutil.ts:382`)
- Sync full-tree walks in watcher rescan / `adopt`. (`workspace-watcher.ts:162-182,254-258`)
- `assertProcessesAllowed` has one caller: `TESTPION_ALLOW_PROCESSES=0` does not stop external-secrets CLIs, git or browser launches.
- Desktop-only modules exported from the core barrel; import previews hold up to 512 MB base64 in a process-wide map; one process-wide fuzz `running` controller; SSE bridge ignores backpressure; RPC contract untyped (`params: any`) and unversioned; run orchestration implemented three times (backend, CLI, MCP) with three dataset caps.
- Extensibility: a new item kind touches 11 files, a new protocol 37, a new AI provider 9; 90+ `kind === '…'` branches outside `kinds/`.

**Performance (engine / backend / CLI / MCP)**
- One fsync'd atomic write per `tp.environment.set` in app runs. (`vars/current-values.ts:69`)
- Full-body parse / deep copy / pretty-print to keep 16 KB / 4,000 chars per send. (`send.ts:184-191`, `execute.ts:421`)
- 17.4 MB main bundle with lazy deps bundled eagerly; CLI ~250 ms eager module work per command (any real command 320-500 ms; cold unbundled fallback 27.8 s).
- Per send: every environment parsed, a payload file for every body, GraphQL payload files never pruned.
- MCP `tools/list` 336 KB for 202 tools; startup scans every test file for `expose:`.
- Debugger proxy memory: unbounded request bodies, UTF-8 round trip of held responses, `gunzipSync` without a limit, quadratic frame concat, deep search lowercasing 200 MB.
- SQLite hygiene: prepare-per-call, LIKE scans, `json_extract` stats; a worker per SQL query; `deleteRunsBefore` sync walk.

**UX / agents**
- Toasts drop the engine's `why` / `suggestions`; raw ECONNREFUSED/ENOENT survive. (`store.ts:510-519`, `errors.ts:145-147`)
- First launch opens the Examples workspace where Get started, the tour and walk-throughs are hidden; a new tab does not focus the URL.
- CLI contract gaps: 22 of 205 leaves refuse `--json`; ~20 writers lack `--dry-run`; `--yes` on 2 commands while MCP confirms on 54 tools (the CLI has no way to ask).
- AI cost invisible where spent: response-bar Explain / Generate tests / Suggest assertions skip preflight; MCP `ai_run_task` returns no usage/cost; no per-call `max_cost_usd` outside RAG.
- No Postman-word map (Runner / Mock / Flows / Globals / Vault / Newman / Interceptor); "New AI test" leads to three places; Debug/Capture/Record is one feature in seven words.
- Postman import activates `event[].disabled: true` scripts and reports "fully".
- Inherited auth shows nothing about what is inherited; OAuth 2.0 has no "Get token" / token visibility.
- Dark-mode primary buttons ~2.9:1 contrast; the e2e a11y step skips 10+ views and all dialogs.
